# ARCHIVO / Terminaciones vectoriales · laboratorio

11 marcas × 7 plantillas por marca = **77 SVG**: cuello S/M/L/XL, firma de manga, frente de colgante y reverso editorial pendiente de copy aprobado. Los logos y símbolos se insertan desde los SVG canónicos existentes, no se sustituyen por fuentes genéricas. Cuello 60 × 35 mm; manga 40 × 16 mm; colgante 55 × 90 mm.

Estos SVG son estudios de composición, no etiquetas reglamentarias completas ni órdenes de impresión. No inventan composición, fabricación, cuidados ni certificaciones. Mantener etiquetas originales de las prendas. Validar técnica, pruebas de lavado/tacto y coherencia del color; definir papel kraft real, impresión, sangrado e imposición.

`hangtag-cut-guide.svg` es una guía magenta (NO imprimir junto al diseño). El reverso deja espacio deliberado para redactar y convertir a curvas el relato de cada colección.

Para PDF industrial o PNG 300 ppp, hablar primero con el proveedor y usar el proceso de preprensa documentado en `docs/production/prepress.md`.
