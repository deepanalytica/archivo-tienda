# Laboratorio vectorial / 11 marcas ARCHIVO

22 SVG: un estudio macro original de 270 x 270 mm y una firma micro de 80 x 80 mm por marca, con sus símbolos canónicos del repositorio. Son propuestas creativas de prototipo, no diseños aprobados para producción industrial ni alteraciones del catálogo. La medida física no valida capacidad efectiva de una plancha nominal 300 x 300 mm. Verificar línea mínima, sustrato, perfil de color, transfer, tacto, adhesión y lavado. No hay fondos de color de tela en los archivos y no se deben usar como comprobación de disponibilidad.
