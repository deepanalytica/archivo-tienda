Guía / principios

El diseño no debe estorbar.

Reglas para que la interfaz se mantenga útil mientras crece el portafolio.

01 / Descubrir

Proyectos en primer plano.

El visitante debe encontrar los trabajos sin hacer scroll por una biografía o efectos introductorios.

02 / Comprender

Cada caso explica qué hizo.

Problema, enfoque, implementación y evidencia. Ninguna métrica inventada.

03 / Interactuar

Animación, no distracción.

El movimiento guía la atención y se reduce si el usuario así lo configura.

Stack de implementación

React + TypeScriptHTML + CSS TokensGSAPReact Bits patternsThree.jsRemotionGStack / QA

GStack estructura la revisión y el control de calidad; no añade componentes gráficos. React Bits ofrece patrones de interacción a adaptar; Three.js y Remotion se cargan solamente cuando el usuario entra a los módulos relevantes.
