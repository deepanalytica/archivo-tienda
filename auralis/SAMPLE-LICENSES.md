# AURALIS Studio · Sample library credits

AURALIS includes a curated, locally hosted subset of the professionally recorded Meta Open Sound instruments:

- **Meta Piano** — 88-key upright piano, 4 velocity layers. CC0 1.0.
- **Meta Nylon Guitar** — six string zones, fingerstyle and two picked dynamics. CC0 1.0.
- **Meta Steel Guitar** — six string zones, 3 dynamic layers. CC0 1.0.

Source: [facebookincubator/Meta-open-sound](https://github.com/facebookincubator/Meta-open-sound), collections tagged `meta-piano-v1.0.0`, `meta-nylon-guitar-v1.0.0`, and `meta-steel-guitar-v1.0.0`.

The original instrument recordings are 48 kHz / 24-bit WAV. AURALIS uses the collection's mono OGG Vorbis web previews in its browser sampler to keep the mobile download and memory footprint manageable. The original WAV masters remain available from the source project releases for future native/desktop integration.

All three instrument collections are released under **CC0 1.0 Universal**. No attribution is legally required; this credit is provided for provenance. The curated sample set uses 16 piano anchor notes with four velocity layers and three anchor notes per guitar string with three dynamic layers. Samples are loaded on demand and cached locally by the PWA after use.
